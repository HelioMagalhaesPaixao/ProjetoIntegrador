# Projeto Integrador - Sistema de Conferência de Preços

## Descrição
Este é um sistema desktop em Java para conferência de preços de produtos anotados pelo usuário e comparados com preços de notas fiscais. Permite cadastro de produtos, registro de notas fiscais e comparação de preços.

## Funcionalidades
- Cadastro de produtos com código pessoal
- Registro de notas fiscais
- Comparação de preços entre anotação do usuário e nota fiscal
- Navegação intuitiva entre telas (Menu, Cadastro, Registro, Comparação)

## Tecnologias
- Java (Swing para interface gráfica)
- MySQL (banco de dados)
- JDBC (conexão Java → MySQL)
- Git e GitHub (versionamento e controle de versões)
